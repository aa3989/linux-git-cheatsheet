## Linux and Git Cheat Sheet ##

# Linux Commands #


# 1. cd
        Changes directories

        Usage:
            cd folder

        Useful tricks:
            cd ..       -- go back one directory
            cd ~        -- go to home directory
            cd -        -- go to previous directory

# 2. ls
        Lists files and directories

        Usage:
            ls

        Useful tricks:
            ls -l       -- detailed view
            ls -la      -- includes hidden files
